Format Studio ヘルプ・プライバシーポリシー

最終更新: 2026-09-05 ／ 対象アプリ: Format Studio（Mac App Store 版・以下「本アプリ」）

1. Format Studio とは

Format Studio は、AI エージェントとの共同作業で頻繁に開く「設定・ドキュメント・スクリプト」を素早く確認・軽く直すための軽量エディターです。IDE の代替ではなく、IDE を立ち上げるまでもない場面のために作られています。動作環境は macOS 13 以降です。

層対象提供するもの
第一級JSON / YAML / Markdownハイライト・整形・構文チェック・ツリー編集・プレビュー・アウトライン
スクリプト.sh .bash .zsh / .bat .cmd / .html .htmハイライト・アイコン・フィルタ・ステータス表示のみ（HTML は「ブラウザで開く」あり）
閲覧のみ画像（png / jpg / gif / webp / svg / avif）表示のみ

2. 基本の使い方

フォルダを開くと、サイドバーにディレクトリツリーが表示されます。ファイルをクリックしてタブで開き、編集・整形・プレビューができます。よく使う操作は以下のショートカットから行えます。

ショートカット動作
⌘Oフォルダを開く
⌘S保存
⌘Wタブを閉じる
⌘R再読み込み
⌘F検索（開いているファイル内）
⌥⌘G行へ移動
⌥⇧Fドキュメントを整形
⇧⌘V分割表示（エディタ＋ビューア）
⇧⌘Eビューアのみ表示
⇧⌘Oアウトライン
⇧⌘Fサイドバーで絞り込み
⌘= / ⌘- / ⌘0文字サイズの拡大／縮小／リセット
⌘1〜⌘9タブの切り替え
⌘Mウインドウをしまう

このほか、表示メニューからライト／ダーク／システムのテーマ切替、行の折り返し、隠しファイルの表示を切り替えられます。Vim モードは編集メニューから有効にできます。外部で変更されたファイルを開いている場合は再読み込みの確認が表示され、未保存のタブがある状態でタブを閉じる・アプリを終了する際には確認ダイアログが表示されます。

Vim モードは編集メニューから有効にします。主な操作は次のとおりです（標準的な Vim の動作で、独自のキー割り当てはありません）。保存は ⌘S で行い、:w や :q などの Ex コマンドによる保存・終了は使えません。

4. プライバシーポリシー

はじめに

本アプリは、利用者が「フォルダを開く」やドラッグ&ドロップ・Finder で選んだフォルダやファイルの内容を、その場で表示・編集するためのエディターです。本アプリは、利用者のプライバシーを最大限に尊重するため、利用者の個人情報を収集・送信しない設計としています。本アプリはサーバを持たず、ネットワーク通信そのものを行いません（唯一の例外は「外部送信・第三者提供・トラッキング」の項で説明する「ブラウザで開く」機能です）。

本ポリシーは、本アプリが取り扱う情報と、その保護のための方針を説明します。

収集・送信する情報

本アプリは、利用者の個人情報を収集・送信しません。

本アプリはサーバを持たず、利用者に関するいかなる情報も、開発者・第三者を含む外部へ送信しません。アカウント登録・ログインは一切行いません。広告配信・アクセス解析（アナリティクス）・トラッキングの仕組みも組み込んでいません。

ファイルへのアクセス（App Sandbox）

本アプリは macOS の App Sandbox 内で動作し、利用者が「フォルダを開く」やドラッグ&ドロップ・Finder で明示的に選んだフォルダ・ファイルにのみアクセスします。それ以外のファイルシステムへのアクセスは、macOS のサンドボックス機構によって制限されています。

端末内に保存される情報

本アプリは、機能の提供に必要な以下の情報を、利用者の端末内（アプリのサンドボックス領域）にのみ保存します。これらはアプリの外部へ送信されることはありません。ファイル本文そのものはアプリが保持せず、保存先は常に利用者が選んだ元のファイルです。

区分具体的な内容目的
設定値テーマ（ライト／ダーク／システム）、文字サイズ、行の折り返し、隠しファイル表示、Vim モード、アウトライン表示、サイドバー幅、ウインドウの位置とサイズアプリの動作・表示のカスタマイズ
お気に入りお気に入りに登録したフォルダよく使うフォルダへの素早いアクセス
前回の状態前回開いていたフォルダと開いていたタブの一覧（ファイルのパス）次回起動時の作業再開
フォルダの参照情報選んだフォルダを次回も開けるようにするための参照情報（macOS の security-scoped bookmark）再度のフォルダ選択なしでのアクセス継続

アプリを削除（アンインストール）すると、これらの情報はすべて消去されます。なお、macOS の Time Machine や iCloud 等のバックアップ機能を利用者が有効にしている場合、これらの情報がバックアップに含まれることがあります。これは OS の仕組みによるもので、開発者がその内容にアクセスすることはありません。

外部送信・第三者提供・トラッキング

本アプリは、ネットワーク通信を行いません。唯一の例外は、利用者が明示的に選択した場合の「ブラウザで開く」機能で、HTML ファイルを macOS の既定アプリ（ブラウザ）に渡すだけであり、本アプリ自身が通信を発生させるものではありません。本アプリに広告配信・アクセス解析・トラッキングの仕組みは組み込まれておらず、情報を第三者へ提供・販売することもありません。

データの確認・削除

端末内に保存された設定値・お気に入り・前回の状態・フォルダの参照情報は、いずれもアプリの動作に付随するものであり、アプリを削除（アンインストール）することで完全に消去されます。利用者が開いたファイル自体は、利用者が選んだ元の場所にそのまま残ります。

本ポリシーの変更

本ポリシーの内容は、機能追加や運用方針の変更に応じて改定することがあります。重要な変更がある場合は、アプリの更新等を通じて周知します。
